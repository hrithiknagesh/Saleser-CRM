# 🚀 Saleser CRM

A modern, high-performance, full-stack CRM web application built with React, TypeScript, Tailwind CSS, Express, and interactive 3D visual effects.

---

## ✨ Features

- **📊 3D Interactive Pipeline**: Real-time 3D orbital deal intelligence visualization powered by HTML5 Canvas and mathematical projections.
- **🌓 Dynamic Light & Dark Mode**: Seamless theme toggling with custom solar lighting animations, radiant ambient sweeps, and high-contrast color schemes.
- **📈 Comprehensive Sales Modules**:
  - **Leads Management**: Filter, search, and track conversion stages.
  - **Deals Pipeline**: Kanban-style deal advancement with probability indicators.
  - **Tasks & Assignments**: Priority-based task tracking with 3D elevation cards.
  - **Contacts & Accounts**: Searchable directories with comprehensive relationship tracking.
  - **Reports & Analytics**: Visual charts with CSV export features.
- **⚙️ Settings & Customization**: Notification preferences with iOS-style toggles, team member management, and company profile settings.

---

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS, Lucide Icons
- **Backend**: Node.js, Express, REST APIs
- **Design & 3D**: Custom 3D tilt effects, perspective depth transformations, and orbital node canvas

## 🚦 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher)
- [Git](https://git-scm.com/)

### Installation & Running Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/<YOUR-USERNAME>/saleser-crm.git
   cd saleser-crm
   ```

2. **Install dependencies**:
   ```bash
   npm install
   cd backend && npm install
   cd ../frontend && npm install
   cd ..
   ```

3. **Start the application**:
   ```bash
   npm run dev
   ```

This concurrently starts:
- Frontend on `http://localhost:5173`
- Backend API on `http://localhost:3000`
