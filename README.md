# 🚀 Saleser CRM

**A Modern Full-Stack Customer Relationship Management Platform**

Saleser CRM is a modern, interactive CRM web application designed to help businesses manage leads, track sales opportunities, organize tasks, maintain customer relationships, and monitor business performance through an intuitive dashboard.

Built with React, TypeScript, Tailwind CSS, and Node.js, Saleser CRM combines a clean user interface with interactive visualizations and powerful sales management tools.

## ✨ Features

- 📊 **Interactive Sales Dashboard** — Visualize sales activities and deal progress.
- 🎯 **Lead Management** — Search, filter, and track leads through different conversion stages.
- 💼 **Deal Pipeline** — Manage sales opportunities with a Kanban-style pipeline and deal probability indicators.
- ✅ **Task Management** — Organize tasks with priority-based tracking and assignments.
- 👥 **Contacts & Accounts** — Maintain searchable customer and business directories.
- 📈 **Reports & Analytics** — View business insights using charts and export reports as CSV files.
- 🌗 **Dark & Light Mode** — Switch between themes for a comfortable user experience.
- 🎨 **Interactive 3D Visualizations** — Explore sales pipeline data through custom canvas-based visual effects.
- ⚙️ **Settings & Customization** — Manage notification preferences, team members, and company settings.
- 📱 **Modern UI** — Enjoy a clean interface with interactive components and responsive design elements.

## 🚀 Getting Started

Follow these steps to run Saleser CRM on your local machine.

### Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/) (v18 or higher)
- [Git](https://git-scm.com/)
- npm (included with Node.js)

### 1. Clone the Repository

```bash
git clone https://github.com/hrithiknagesh/Saleser-CRM.git
```

### 2. Open the Project

```bash
cd Saleser-CRM
```

### 3. Install Dependencies

Install the root dependencies:

```bash
npm install
```

Install the backend dependencies:

```bash
cd backend
npm install
```

Install the frontend dependencies:

```bash
cd ../frontend
npm install
```

Return to the root directory:

```bash
cd ..
```

### 4. Run the Application

From the root directory, run:

```bash
npm run dev
```

If the root development script is configured to start both services, open the following URLs:

- **Frontend:** http://localhost:5173
- **Backend API:** http://localhost:3000

If the command does not start both services, check the scripts in the root, frontend, and backend `package.json` files and start each service using its configured development command.
